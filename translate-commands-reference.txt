# Translate commands — one per language

Copy-paste the line for whichever language you're activating. Remember to
first uncomment that language's line in scripts/translate-feature-page.js's
LANGUAGES array before running its command below, or the script will stop
and remind you to do that.

Run these from inside C:\Dev\xpressable-website

## Already done
node scripts/translate-feature-page.js es Spanish Español
node scripts/translate-feature-page.js hi Hindi हिन्दी
